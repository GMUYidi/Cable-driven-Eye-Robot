
Cable-driven Eye Robot Dataset and Codes
========================================

This repository contains the source code, datasets, and related resources for the research project "Cable-driven Eye Robot for Human Vision Visualization and Strabismus Diagnosis".
The data and codes are organized into the following folders:

Folder Structure
----------------

1) control code
- Contains all the control programs for the robotic eye platform.
- Includes inverse kinematics, open-loop control, PID control, and communication code with actuators and sensors.

2) Data for testing pure open-loop control accuracy
- Data collected from experiments using pure open-loop control.
- Used to evaluate the positioning accuracy of the robotic eye without feedback control.

3) Eye tracker data
- Eye gaze data collected from healthy participants using an eye tracker.
- Used to reconstruct and analyze human eye trajectories.

4) Plot Homographic matrix
- MATLAB or Python code to calculate and plot homography matrices.
- Helps visualize and simulate binocular vision fusion based on recorded eye movements.

5) Robotic eye 3D design created using Fusion 360
- 3D models and CAD design files of the cable-driven robotic eye.
- Created using Autodesk Fusion 360 for mechanical design and fabrication.

6) Strabismus Severity
- Data and scripts used to simulate and quantify strabismus visual symptoms.
- Used for reproducing patient vision scenarios and severity analysis.

7) video
- Videos demonstrating the robotic eye movements and binocular view synthesis.
- Includes healthy vision, strabismus simulation, and calibration videos.
