# Binocular Visualization Pipeline

This folder archives the scripts used to generate the Hess-matched binocular
visualization videos in `../hess_matched_results/`.

These scripts are experiment-pipeline code, not the real-time robot-control
runtime. They are kept here so the generated videos are traceable and so future
work can gradually refactor the pipeline into cleaner reusable modules.

## Pipeline Stages

```text
robotic-eye capture / replay
  -> healthy binocular baseline frames
  -> Hess-chart extraction and interpolation
  -> simulated strabismus gaze trajectory
  -> homography matching / frame warping
  -> cropped and stabilized binocular video
  -> optional gaze overlay
```

## Folder Layout

```text
pipeline/
  acquisition/                  robot capture/replay scripts for the healthy baseline
  hess_chart/
    app_functions/              MATLAB helper functions for Hess-chart point extraction
    bilinear_interpolation/     Hess interpolation and strabismus trajectory simulation
  makevideo/                    video stitching, homography, repair, crop, and overlay scripts
```

## Relationship To Results

The final uploaded results live in:

```text
experiments/binocular_visualization/hess_matched_results/
```

For each strabismus subject, the result folder includes the final video,
homography/report metadata, and matrix files. Intermediate frame folders are not
committed because they are large and can be regenerated by the pipeline.

## Current Status

This folder is an archived research pipeline. The scripts preserve the actual
workflow used to create the current videos, including subject-specific repair or
refinement scripts. The next engineering step is to convert the repeated logic
into a single parameterized command-line pipeline.
