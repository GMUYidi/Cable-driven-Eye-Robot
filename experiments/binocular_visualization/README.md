# Binocular Visualization Experiments

This folder groups outputs related to reconstructing and visualizing binocular
vision from two robotic-eye viewpoints.

```text
binocular_visualization/
  homography/               homography estimation and visualization scripts
  strabismus_severity/      strabismus severity data and plotting scripts
  pipeline/                 archived generation scripts for visualization videos
  hess_matched_results/     final Hess-matched binocular videos and metadata
```

These are experiment outputs and analysis tools, not core runtime control code.
