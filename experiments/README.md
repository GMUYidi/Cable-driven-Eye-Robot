# Experiments

This folder stores datasets, analysis scripts, and outputs from robotic-eye and
binocular-vision experiments.

```text
experiments/
  open_loop_accuracy/          pure inverse-kinematic control accuracy tests
  eye_tracking/                participant eye-tracking trajectories
  binocular_visualization/     homography and strabismus visualization outputs
```

Reusable calibration files belong in `calibration/`. Videos belong in
`media/videos/`. Runtime software belongs in `src/` and `demos/`.
